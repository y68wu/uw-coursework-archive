# CS135 — Racket coursework

Source files are grouped by assignment number (A01–A09). Topics include recursion, lists, trees, search, and functional programming. This is an archival copy of coursework, not a standalone application.

`A04/a04bonuslib.rkt` and `A07/fs-print.rkt` are course-supplied helper files; they are included only to preserve context for the exercises. Assignment statements, solution PDFs, backup files, and screenshots are not included. Original source files remain in the local course folder.
