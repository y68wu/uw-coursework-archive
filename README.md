# University of Waterloo Coursework Archive

Private archive of course-related source code that is not suitable for a public portfolio. Folders are organized by course; only code and notebooks are copied here. Course handouts, grading material, solution PDFs, virtual environments, binaries, and local editor state are excluded.

The CS245 folder inspected locally and remotely contains no code project; it is intentionally not mirrored here. Remote CS488 assignments are in the separate private [`cs488-coursework`](https://github.com/y68wu/cs488-coursework) repository. The larger CS246 Quadris, CS241 compiler, CS350 OS, CS370 numerical methods, CS398 WebGL, and CS452 kernel projects have their own repositories. Duplicate remote snapshots and course-distributed frameworks are not mirrored here as separate projects.

This repository is private because course rules and third-party starter material may restrict public distribution. The code is shared for personal archival and individually authorized review, not as a public solution bank. Some helper files were supplied by courses and are not claimed as original work. Student identifiers have been removed from copied headers. Remote source was imported on 2026-09-21; the original Waterloo files were not modified.
