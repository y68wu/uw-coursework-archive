# University of Waterloo Coursework Archive

Private archive of course-related source code that is not suitable for a public portfolio. Folders are organized by course; only code and notebooks are copied here. Course handouts, grading material, solution PDFs, virtual environments, binaries, and local editor state are excluded.

| [`cs370/`](cs370/) | Numerical-methods notebooks from assignments A3–A4 | Local course folder |

The CS245 folder inspected locally contains course PDFs, not a code project; it is intentionally not mirrored here. Other remote coursework will be added only after its contents and duplicates are checked.

This repository is private because course rules and third-party starter material may restrict public distribution. The code is shared for personal archival and individually authorized review, not as a public solution bank. Some CS135 helper files were supplied by the course and are not claimed as original work. Student identifiers have been removed from copied headers.
